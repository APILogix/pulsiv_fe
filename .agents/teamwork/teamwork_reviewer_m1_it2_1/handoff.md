## 2. Logic Chain

1. **Root-Cause Elimination of Sidebar Mount CLS (0.2711 -> 0.0000)**:
   - In Iteration 1, `AppDualSidebar` mounted with `isFlyoutOpen: true` (272px wide), after which a post-mount `useEffect` determined that `/dashboard` had 0 inner children and toggled `setIsFlyoutOpen(false)`. Because CSS width transitions were unconditionally active, the container animated down to 0px over 240ms, causing 9 animation frames of lateral displacement for the main flex container (0.2711 CLS).
   - In Iteration 2, `isEffectiveFlyoutOpen = isFlyoutOpen && hasInnerItems` derives geometry **synchronously during React render**. On routes without inner items (such as `/acme/dashboard`), the container renders `w-0 opacity-0 border-r-0` on **Frame 1**.
   - The addition of `hasMounted` ensures that CSS transitions are suppressed until hydration/mount completes. Subsequent user clicks toggle the sidebar smoothly with `hadRecentInput: true`, which the W3C Web Vitals specification excludes from CLS.
   - Defaulting accordion groups to open (`expandedGroups[groupName] ?? true`) eliminates the post-mount vertical expansion shift (0.0619 CLS) on module pages like `/acme/observability`.

2. **Elimination of Edge Fallback HTML Caching Hazard**:
   - `public/auth/` contains 0 static assets following dead asset cleanup in Iteration 1.
   - Retaining `/auth/*` in `public/_headers` exposed edge CDNs (Cloudflare Pages, Netlify) to caching the fallback `index.html` document for 7 days whenever clients visited `/auth/login`.
   - Removing `/auth/*` and adding an explicit `/` entry with `Cache-Control: no-cache, no-store, must-revalidate` guarantees that all direct SPA entries and fallback navigations receive strict revalidation directives.

3. **Authentic Testing of Public Guest Routes**:
   - Previously, the audit harness injected `sessionStorage['auth-storage']` globally on all CDP document navigations. When navigating to `/auth/login`, `<RequireGuest />` triggered `<Navigate to="/dashboard" />`, falsely attributing authenticated dashboard shifts to guest routes.
   - Dynamic CDP script registration and unregistration in `prepareAuthContext()` guarantees that public routes execute in an unauthenticated environment without spurious redirects.

4. **Integrity & Anti-Cheat Verification**:
   - No hardcoded metric returns were found in `src/app/layouts/AppDualSidebar.tsx`, `scripts/audit-cwv.mjs`, or `scripts/challenge-m1-assets.mjs`.
   - The CWV harness in `scripts/audit-cwv.mjs` directly attaches a real browser `PerformanceObserver` observing `layout-shift`, `largest-contentful-paint`, and `first-contentful-paint`.
   - Zero facade logic or shortcuts detected.
